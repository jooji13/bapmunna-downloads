# 밥뭇나 갤럭시 테스트 앱

[밥뭇나 설치 안내](https://impact-series.web.app/bapmunna/app/health/)에서 갤럭시를 선택하고 테스트 앱을 내려받으세요.

이 저장소는 공개 테스트 설치 파일만 제공합니다. 전체 앱 소스, 계정 정보, 서명 개인키는 포함하지 않습니다.

- 걸음수 전용 모듈입니다. 로그인·튜토리얼·가족 화면은 [기존 밥뭇나 웹앱](https://impact-series.web.app/bapmunna/app/)에서 이용합니다.
- Android 10 이상, 삼성 헬스와 Health Connect의 걸음수 공유가 필요합니다.
- 오늘의 삼성 헬스 걸음수만 휴대폰에서 읽으며 서버나 가족에게 보내지 않습니다.
- 테스트 버전 0.1.0-test.1입니다. Play 스토어 출시본이 아니며, 실제 휴대폰 설치·권한·건강 기록 비교는 아직 검증하지 않았습니다.
- iPhone 설치 파일과 TestFlight 링크는 아직 없습니다. 소스 압축 파일을 설치 파일로 제공하지 않습니다.

## 설치

1. 갤럭시에서 `bapmunna-health-0.1.0-test.1.apk`를 내려받고 파일을 엽니다.
2. 휴대폰이 설치 허용을 물으면 위 공식 안내에서 받은 파일인지 확인한 뒤 직접 선택합니다. 설치 후에는 브라우저의 해당 허용을 다시 끕니다.
3. 앱을 열고 ‘걸음수 연결’ → 이용 안내 동의 → OS 걸음수 읽기 권한을 확인합니다.
4. 삼성 헬스 설정에서 Health Connect 걸음수 쓰기를 켠 뒤 밥뭇나에서 다시 확인합니다.
5. 권한 창이 열리지 않으면 앱의 ‘걸음수 이용 안내’ → ‘휴대폰 설정 열기’에서 확인합니다. 기기가 차단하면 보안 기능을 끄지 말고 담당자에게 안내 문구를 알려 주세요.

이전 개발용 APK가 설치돼 있으면 서명이 달라 삭제 후 설치가 필요할 수 있습니다. 밥뭇나의 동의 설정은 초기화되지만 삼성 헬스의 건강 기록은 삭제하지 않습니다.

앱 연결 끄기는 밥뭇나의 조회를 멈춥니다. OS의 읽기 권한은 Health Connect 설정에서 직접 철회할 수 있습니다.

## 파일 확인

Release의 `SHA256SUMS.txt`와 `release.json`에서 APK 해시·서명 인증서 지문·버전·실기기 미검증 상태를 확인할 수 있습니다. GitHub가 자동으로 붙이는 Source code ZIP/TAR는 이 안내 저장소의 내용이며 설치 파일이 아닙니다.
